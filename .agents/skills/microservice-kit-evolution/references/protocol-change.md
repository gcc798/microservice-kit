# 契约、配置和可观测性变更

## Proto/API

- 先判断是否破坏兼容性；无兼容要求时也必须更新所有调用方和测试。
- 不手改生成文件，运行项目规定的生成和检查命令。
- 更新 `native/docs/protobuf.md` 仅在协议规则发生变化时更新，不为单个字段复制整篇规范。

## 配置

- 配置属于使用它的服务；禁止恢复共享全量 `Config` 或 `Shared()`。
- 新字段同时更新服务的 `conf.example.yaml`、配置绑定、配置文档和必要的启动校验。
- 删除字段时清理代码、模板、环境变量说明和旧文档。

## 链路追踪

- 新的 HTTP、gRPC、Redis、数据库边界必须保持 context 和 trace 传播。
- 更新 `native/docs/opentelemetry.md` 仅在采集、传播、命名或敏感数据规则变化时更新。
